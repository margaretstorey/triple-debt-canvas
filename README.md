Triple Debt Sprint Canvas

A one-file, printable canvas for teams to reflect on **technical**, **cognitive** and **intent** debt each sprint, including how they use AI tools and commitments they make to address these debts.

- Technical debt lives in the code.
- Cognitive debt lives in people (shared understanding across the team).
- Intent debt lives in artifacts, or their absence (rationale, goals, constraints, decisions).

Based on the Triple Debt Model:

Storey, M. (2026). *From Technical Debt to Cognitive and Intent Debt: Rethinking Software Health in the Age of AI.* ACM Queue. https://queue.acm.org/doi/10.1145/3807966

## Use it

Open the live page, fill it in, and use **Print / export PDF**. Use **Print blank form** for a handout.
#
Suggested flow: each person fills it in individually first, then the team fills in one together.

There is no server and no data is stored. Everything stays in your browser, so print or save a PDF to keep your answers.

## Run it locally

Open `index.html` in any browser.
